# Poll System

Poll System is a lightweight Python application for creating and managing local polls.

## Features

- Create polls
- Multiple answer options
- Vote counting
- JSON storage
- Result export
- Statistics

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python src/main.py
```

Example

```
1. Create poll
2. Vote
3. Results
4. Export
5. Exit
```
